Server Required

Online matchmaking needs the backend app

GitHub Pages can host this standalone index.html, but it cannot run PostgreSQL, Drizzle ORM, or Next.js API routes. Local mode and Bot mode work here, while live matchmaking must open your deployed fullstack app.

Deploy the full Next.js app to a server platform such as Vercel, Railway, Render, or Fly.io with a PostgreSQL database, then paste that app URL here. It will be saved in this browser.

Tip: If you deployed only this HTML file to GitHub, online matchmaking cannot work there. Deploy the complete project folder as a Next.js app for online play.
